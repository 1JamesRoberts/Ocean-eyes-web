The short answer

OceanEyes is close to the compact end of mainstream dashboard typography, with one notable exception.

OceanEyes body 15px

Current default body size, with a 1.45 line-height.

Common body center 16px

The most reusable cross-platform baseline in the comparison.

OceanEyes caption 13px

Aligned with Apple footnotes and Fluent mobile captions.

Navigation label 10px

Below the published 11–13px range used by many mobile systems.

↗

Recommendation

Keep the 13px captions, 16px card titles, and 24px section headings. For a more conventional health-app baseline, raise primary body copy to 16px/24px and navigation labels to 11–12px/16px. That preserves density while improving readability and alignment with Material, Fluent, and Apple conventions.

How the current tokens compare

  • Body 15px: valid for dense cards and matches Fluent iOS Body 2, but below the default Apple iOS and Material reading baseline.
  • Caption 13px: a strong choice for secondary metadata.
  • Title 16px: appropriate for card and row titles, not a full page heading.
  • Section 24px: aligned with common dashboard heading sizes.
  • Navigation 10px: the clearest candidate for an accessibility/readability increase.

Evidence boundary.

Apple, Material, Fluent, Atlassian, Shopify, Carbon, Primer, Adobe, Fitbit, and Garmin publish numeric values. Samsung and WHOOP publish roles and scaling guidance but not a complete current mobile pixel scale. Private production apps can override their platform system, so these are defensible benchmarks—not a claim that every screen in each app uses one identical size.

OceanEyes’ current values come from lib/core/theme/oceaneyes_tokens.dart and docs/visual_tokens.md.
