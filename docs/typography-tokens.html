Usage Patterns

observed app conventions
Headings
Bold, tight, and compact

Base headings use font-weight: 700 and letter-spacing: -0.02em. Large mobile headings often use font-weight: 800.

Labels
AQUARIUM STATUS

Metadata and section labels use small sizes, semibold or bold weight, and wider uppercase tracking for scanability.

Body Copy

Body text stays near 14-16px with relaxed percentage line heights such as 145% or 150% when explanatory content needs easier reading.

Controls
Start Monitoring

Buttons and inputs use --font-main, usually 14px or 15px, with semibold weight for clear touch targets.
