Core Utility Styles

@utility type-*

Apart from hero, metric, status bar, dense chart, and technical overlay text, use these five styles for hierarchy. All use --font-main and letter-spacing: -0.01em.

Class Spec Sample Typical Use
.type-title 18px / 1.3 / 700 / black Water Chemistry Card titles, sheet headings, major compact section labels.
.type-strong 16px / 1.35 / 600 / black Start Monitoring Buttons, important row labels, selected states, compact headings.
.type-body 16px / 1.45 / 400 / black Aquarium readings are stable. Primary body copy, input values, normal readable text.
.type-body-muted 16px / 1.45 / 400 / black at 70% Last update synced one minute ago. Secondary explanations, supporting copy, less prominent values.
.type-caption 14px / 1.35 / 400 / black at 70% Confidence 94% Captions, labels, metadata, badges, compact helper text.

Current Usage Rules

implementation conventions
Hierarchy

Prefer the utility classes over ad hoc Tailwind text sizes for normal UI copy. Use bold only for title and strong emphasis.

Controls

Glass buttons and outline buttons align to 16px bold. Glass inputs align to 16px regular.

Exceptions

Hero titles, large metrics, donut totals, status bar text, bottom nav micro labels, and live debug overlays may keep specialized sizes.

Legacy Tokens

--text-display, --text-hero, and other old size tokens still exist in @theme for compatibility, but they are no longer the default hierarchy for ordinary UI text.
